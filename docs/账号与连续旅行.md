# 邮箱账号与连续旅行 · 2026-11-14

## 用户体验

- 右上角「登录 / 注册」使用邮箱验证码，首次成功验证自动注册。未登录仍可使用生成、编辑、收藏和手记。
- 与已有 Waywise 账号使用相同邮箱；成功验证后只读匹配同邮箱的其他产品，显示关联名称。各产品仍分别维护登录会话，没有伪称已实现跨站单点登录。
- 登录时可显式迁移访客记录。按记录 ID 合并，保留已有云端版本；成功同步后才清除访客副本。未选择迁移不会导入访客内容。
- 云端保存旅行偏好、收藏、手记、当前期待及草案；每次登录后的生成自动保留独立历史，未收藏也能找回。
- 跨设备修改使用 revision 防止旧页面静默覆盖。冲突时保留本机修改，支持先导出再加载云端；会话失效可以重新验证。
- 退出后回到独立访客空间。账户缓存按用户 ID 分离，退出删除对应缓存，未同步记录不带到其他账号。

## 记忆如何参与生成

服务器从当前登录账号取得可编辑的明确偏好、最近五条手记和选择理由、最近三次规划摘要。模型会区分「规划过」和「真实经历」，过去偏好服从本次输入。编辑示例不作为个人偏好证据。

账号里可关闭后续记忆，生成前也可单次取消；关闭时后端不读取记忆给模型。邮箱、验证码、会话、其他产品记录都不会进入模型上下文。

## 验收

- 九组自动测试通过：验证码生命周期、重试/过期/重放、邮箱规范化、会话散列、账号隔离、资料 revision、历史所有权、删除级联、记忆开关及不含邮箱、模型修正及额度。
- 隔离浏览器：访客全流程保持可用；选择迁移、保存偏好、退出隔离、清空浏览器缓存后再次登录恢复云端资料、390 像素账号与历史布局通过。
- 已有 SMTP 的 TLS 登录成功，未发送真实测试邮件；实际收信需要用户点击获取后核实。
- 生产同邮箱桥接只读识别五个现有产品账号，未复制其他产品密码、密钥或业务内容。

截图见 `screenshots/account-desktop.png`、`account-mobile.png` 和 `history-mobile.png`。

生产完整闭环也已通过：临时虚构账号的 HTTPS 校验登录、云端保存、带记忆的真实模型生成、历史自动留档，以及删除测试账号后会话撤销。测试验证码只在进程内使用，不输出、不发真实邮件、不保留测试账户。

关联索引每五分钟更新，登录时读取最新可用索引；各产品会话仍独立。根用户私有索引仅有邮箱 HMAC 与产品名，登录桥接保持只读挂载，不取得其他产品数据目录的写权限。
